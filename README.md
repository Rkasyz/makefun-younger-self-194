A one-line entry for the make.fun competition "One Line to Your
Younger Self": the single line its writer would send back to their
younger self if one line were all they got.

## The entry (140 characters)

> The tabs will never close themselves, 'buy the dip' is a lie, and the girl you like already likes you back. Go talk to her before 2019 ends.

140 characters, one line, inside the gate of 1–200 characters. Three
hard-won truths from a life actually lived — the tabs, the dip, the
girl — and then one imperative that stings: the window it names,
before 2019 ends, is already closed.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` into the output directory, containing exactly
the line above, with no trailing newline.
